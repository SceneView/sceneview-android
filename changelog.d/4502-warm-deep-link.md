- **Android demo: a link opens its demo when the app is already running ([#4502](https://github.com/sceneview/sceneview/issues/4502)).** A `sceneview://demo/<id>` link sent to a running app either did nothing — when it was the very link the app had been started with, Android only brought the app forward — or started a second copy of the app's screen on top of the first, replaying the splash and leaving Back to walk through every copy. The link is now delivered to the screen that is already there: the demo it names opens over Home, replacing any demo that was open, and Back returns to Home as it does after a cold start. A link to the demo already on screen with another `?tab=` switches to that tab.
