- **Android AR: leaving an `ARSceneView` no longer freezes the next screen for a third of a second.** When an `ARSceneView` left the composition, ARCore's `pause()` and `close()` ran on the main thread — about 350 ms of camera teardown on a Pixel 4a, twenty frames during which the screen a Back landed on stood still. The session now counts as closed at once on the main thread (`onSessionPaused` still runs there, while the session is valid), and ARCore's pause and close run on a background thread. A session that resumes before they are done waits for them, and the camera goes back to another resumed `ARSceneView` only once it has been released. A session that is recording still closes inline, so the recorded file is complete when the recorder returns it.
