- **Model Viewer: picking a catalogue model shows a 3D model you can pinch and spin, and the zoom
  no longer leaks from one model to the next.** A catalogue entry with no bundled stand-in (AirPods,
  IKEA KALLAX, every product shelf) showed only its card's still render until the user found and
  tapped the HD pill — so pinch, drag and "Spin scene" visibly did nothing. Picking one now fetches
  its own file on Wi-Fi straight away (never on mobile data, where the pill still offers "Download
  now", size first). The pinch/slider distance is an absolute number of metres and was kept across
  picks: a pinch-out on the earbuds left the next helmet a small speck. It now resets when a new
  model reaches the stage; a `camera_distance` deep link still applies to the first model.
