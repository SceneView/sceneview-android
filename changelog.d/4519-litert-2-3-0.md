- **`arsceneview-depth-ml` moves to LiteRT 2.3.0 ([#4519](https://github.com/sceneview/sceneview/pull/4519)).** LiteRT now ships as three AARs (`litert`, `litert-api`, `litert-gpu`); the module declares `litert-gpu` so `DepthAnythingV2Estimator(backend = Backend.Gpu)` keeps its OpenCL/OpenGL accelerator, now on armeabi-v7a too. Native code per ABI: arm64-v8a ≈ 9.4 MB, x86_64 ≈ 12.2 MB, armeabi-v7a ≈ 6.3 MB. No API change.
