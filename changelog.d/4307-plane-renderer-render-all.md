- **Android AR: `ARSceneView` now draws every detected surface, not only the one in the centre of the screen ([#4307](https://github.com/sceneview/sceneview/issues/4307)).** The default plane renderer used to be the textured grid in `PlaneRendererMode.RENDER_CENTER`. The dots renderer that replaces it always defaulted to `RENDER_ALL`, so an app that never picked a renderer now shows all the floors, walls and ceilings ARCore tracks. `ARSceneView` has no parameter to go back to the centre-only behaviour. A `PlaneRenderer` that you build and drive yourself still accepts `planeRendererMode = PlaneRenderer.PlaneRendererMode.RENDER_CENTER`. To hide the surfaces entirely, pass `planeRenderer = false`.
