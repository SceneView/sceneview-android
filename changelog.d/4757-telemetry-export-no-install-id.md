- **Telemetry worker: `/v1/export` no longer returns `install_id` ([#4757](https://github.com/sceneview/sceneview/issues/4757)).** The CSV keeps one row per event but drops the `install_id` column, raw or hashed, so an exported file cannot be joined back to an install. Distinct-install counts stay available from `/v1/stats`, `/v1/top-clients` and `/v1/funnel`. The read routes also accept the `Bearer` scheme in any case (`bearer <token>`), and when `STATS_TOKEN` is not configured they answer the same `401` as for a wrong token instead of `503`, so a caller cannot tell whether the secret is set; the worker logs the missing secret instead.
