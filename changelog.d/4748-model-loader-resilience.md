- **A failed `ModelLoader.load*Async` no longer crashes the app or stops the loader, and `clear()` no longer ends it ([#4748](https://github.com/sceneview/sceneview/pull/4748)).** A missing file, an unreachable URL or an unparsable payload is now logged and reported as `null` (an empty list for `loadInstancedModelAsync`) on the main thread, instead of reaching the app's uncaught-exception handler and leaving every later `load*Async` a silent no-op. `clear()` cancels the loader's running loads only, and neither `clear()` nor `destroy()` cancels anything else in a `coroutineScope` passed to the constructor; such a scope's `CoroutineExceptionHandler` no longer receives load failures. A model created before a load fails (not only when it is cancelled) is destroyed instead of staying registered. A missing external resource of a `.gltf` (a `.bin`, a texture) is logged and skipped: the model loads without it, as before, and a `.gltf` at the root of `assets/` now finds its resources. `rememberModelInstance(loader, "models/x.glb")` now converts 3MF/STL/OBJ/PLY and transcodes WebP textures off the main thread, like the URL overload, and both overloads log a failed load instead of swallowing it.
