- **A failed `ModelLoader.load*Async` no longer crashes the app or stops the loader, and `clear()` no longer ends it ([#4748](https://github.com/sceneview/sceneview/pull/4748)).** A missing file, an unreachable URL or an unparsable payload is now logged and reported as `null` (an empty list for `loadInstancedModelAsync`) on the main thread, instead of reaching the app's uncaught-exception handler and leaving every later `load*Async` a silent no-op. `clear()` cancels the running loads only; `destroy()` still ends the loader. `rememberModelInstance(loader, "models/x.glb")` now converts 3MF/STL/OBJ/PLY and transcodes WebP textures off the main thread, like the URL overload, and both overloads log a failed load instead of swallowing it.
