- **Demo app: an Object scan stays an object scan after it is saved ([#4683](https://github.com/sceneview/sceneview/issues/4683)).** A saved scan now records whether it was a Room or an Object scan. Scans saved before this change read as Room. A reopened object scan does not show room measurements, floor coverage or a floor plan in its export sheet. Without raw depth, an object scan now applies its arm's-length cutoff to ARCore's feature points and planes, so walls across the room no longer end up in the scan. This needs no new permission. A room survey that finishes after a new home scan has started is no longer added to the new home.
