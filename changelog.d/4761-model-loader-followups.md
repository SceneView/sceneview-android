- **`ModelLoader` no longer blocks the main thread when gltfio refuses a model's resource load, and keeps the cause of a missing `.gltf` buffer ([#4761](https://github.com/sceneview/sceneview/pull/4761)).** A load gltfio refuses (its meshopt-compressed data cannot be decoded) is now detached without `asyncCancelLoad`, whose engine `flushAndWait` ran on the main thread, and its resource data is evicted; the model is still destroyed and the load still fails, with a message naming meshopt. The synchronous `createModel` and `createInstancedModel` parse the glTF JSON only when a resource is missing, instead of on every load on the main thread. When a resolver's `IOException` makes a buffer missing, the thrown `IllegalArgumentException` now carries it as its cause, and each missing resource is logged once instead of twice.
