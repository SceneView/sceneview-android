- **`ModelLoader` no longer blocks the main thread when gltfio refuses a model's resource load, and keeps the cause of a missing `.gltf` buffer ([#4761](https://github.com/sceneview/sceneview/pull/4761)).** A load gltfio refuses (its meshopt-compressed data cannot be decoded) no longer goes through `asyncCancelLoad`, whose engine `flushAndWait` ran on the main thread: the refused model is destroyed at once and its resource data evicted, and the load still fails, with a message naming meshopt. An earlier model whose textures are still decoding stays the tracked load, so destroying it still waits for, or cancels, its decoding first. The synchronous `createModel` and `createInstancedModel` parse the glTF JSON only when a resource is missing, instead of on every load on the main thread. When a resolver's `IOException` makes a buffer missing, the thrown `IllegalArgumentException` now carries it as its cause, and each missing resource is logged once instead of twice.
