- **Demo — AR debug layers no longer abort the app when no frame is drawn for a while** ([#4750](https://github.com/sceneview/sceneview/pull/4750)). The shared debug-mesh layer behind Measure's live walls, 3D Scan, Replay, Dollhouse and the scan ground queued a new buffer upload on every update, and each one pinned JNI global references until Filament drew a frame; with the camera paused (an ARCore recording at its end, a still phone) the table overflowed and the process aborted. Each layer now keeps one upload in flight and sends only the latest state once Filament lets go of the previous one.
