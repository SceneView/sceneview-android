- **Android demo (debug builds only): AI Scene, a prototype where an AI rebuilds a scanned room, then furnishes it ([#4573](https://github.com/sceneview/sceneview/pull/4573)).** It works on the bundled ARCore session: its points, planes, keyframes and camera trail. You can also scan the room you are in: "Scan this room" records the same data live with ARCore and hands it to the same tools. The code reads the whole scan first and proposes what it found — the wall lines, the gaps in them, the furniture as point clusters, the ceiling height — and the AI chooses: which lines bound the room, which gaps are doors or windows, what each cluster is. The code then closes the walls into a plan and measures it: area, perimeter, every wall length, every opening. A gap hidden behind furniture is refused as an opening, and a wall that no scanned point backs is refused too. The AI then places furniture at catalogue size and reads the paint takeoff. The room is drawn as a room: plaster walls, an oak floor, a framed window and soft shadows. Recognised objects and placed furniture use real catalogue products fitted to what the scan measured. Every length, area and clearance comes from the code, not the model, and every step can be undone. On the bundled session a recorded conversation plays by default, and its replies are written from what the tools returned, refusals included. Rebuilding your own scan needs your own Claude or Gemini API key, selected in Settings and kept separately encrypted in the Android Keystore; without one, Rebuild and Furnish stay off and the screen says so. Captures with a dense cloud pass its points and normals to the reconstruction tools. A dimensioned floor plan shows measured wall lengths, openings, object footprints, area, perimeter and ceiling height. A scripted synthetic-room QA state exercises the capture-to-reconstruction path without a key; live providers have up to six rounds and are asked to batch independent tool calls. The AR debug view no longer crashes on a light/dark switch or a new replay: its layer nodes are rebuilt with their materials instead of drawing freed textures.
- **`sceneview-ai`, the provider-agnostic layer the AI Scene runs on ([#4573](https://github.com/sceneview/sceneview/pull/4573)).** One `AiProvider` interface, two implementations (Claude, Gemini) and a scripted one for tests, one conversation loop, strict JSON Schema tools that an MCP server can publish as they are, and a usage log with tokens, latency and cost per round. A provider talks either to the vendor with the user's key or to a SceneView relay with a SceneView token — same request body, same codec. Not published to Maven Central yet; the demo consumes it as a project module.
