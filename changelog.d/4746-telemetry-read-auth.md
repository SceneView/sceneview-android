- **Telemetry worker: the read endpoints fail closed without `STATS_TOKEN` ([#4746](https://github.com/sceneview/sceneview/pull/4746)).** `/v1/stats`, `/v1/timeseries`, `/v1/top-clients`, `/v1/funnel` and `/v1/export` now answer `503` when the secret is not configured, instead of serving data to anyone. A missing or wrong bearer gets `401`, and the token is compared in constant time. CORS `*` now covers only the ingestion routes (`/v1/events`, `/v1/batch`) and `/health`, and ingestion itself is unchanged. Set `STATS_TOKEN` with `wrangler secret put STATS_TOKEN` before deploying.
