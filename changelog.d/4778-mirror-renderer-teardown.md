- **Android: leaving a scene that was being recorded no longer holds the main thread until the GPU's whole queue has run ([#4778](https://github.com/sceneview/sceneview/pull/4778)).** The extra renderer that `SurfaceMirrorer` draws the recording with was destroyed on the spot when the scene left composition, and Filament makes that call wait for every command already queued on the GPU thread — seconds right after a scene appeared, enough for an ANR. It is now released on the main thread, as before, once everything queued before the teardown has executed, like the scene's own renderer since #3854. Filament's release still waits for the work queued since the teardown (the next screen's shader compilation, say), so a shorter wait, bounded by that work, can remain.
