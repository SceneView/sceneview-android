- **Demo: Measure review follow-ups ([#4600](https://github.com/sceneview/sceneview/pull/4600)).** The reticle now snaps to the floor's edges and to walls in every mode, with the same snap radius as table edges: in Distance mode on any tracked plane's outline, in Wall and Room modes on the floor patches and on the foot of each wall (its tracked polygon dropped to the floor). It still only snaps to real ARCore polygons, never to guessed edges. The first corner of a wall or a room can be aimed on the wall itself and drops to the floor when one is tracked. Distance mode gets a Done action that ends the current line, so the next point starts a new one instead of chaining forever. Rising walls follow the wall the aim actually crosses first. The floor fill reuses sceneview-core's `Earcut` instead of a local ear clipper, and the replay's room dimensions use the same metric or imperial format as every other Measure figure.
