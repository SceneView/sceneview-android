- **Web viewer** (`sceneview.js`, behind `/view`, `/open`, the playground and the web demo): ten site models that rendered black, empty or not at all now show. Embedded `EXT_texture_webp` images are re-encoded to PNG before Filament.js reads the file (guitar, Canon EOS RP, DJI Mavic 3, JBL Tour One M3, motorcycle helmet, school backpack). Quantized positions (`KHR_mesh_quantization` with meshopt) get their real bounding box, so the Rolex and the Vibe sneaker are framed at their size instead of as a speck. A skin over 256 joints is split per mesh instead of failing to parse, and a skinned model at rest shows its bind pose instead of its raw mesh. When `loadModel()` is called again before the previous file is shown, the newest call wins and the older one rejects with an `AbortError`, whichever file finishes downloading first, and it stops transcoding textures as soon as it is replaced. On the home page, tapping a model chip while the first model is still loading now shows the tapped model instead of falling back to the still poster. The MCP 3D viewer widget no longer shows "was replaced by a later loadModel() call" when the host re-renders it mid-load (a theme change, new tool output), and a model that loads clears any earlier error. A model that stores several quantized meshes with the same raw box no longer logs a false "kept a wrong bounding box" warning (the home page's Night Circuit). The playground's Web multi-model snippet now creates one viewer per model, since a second `loadModel()` on a viewer replaces the first. The playground offers three.js's Expressive Robot (CC0) instead of Kindred, whose source file is broken (hair and tail sit far above the body). The web demo shows the Switch OLED, opening on its screen, instead of a Sketchfab diorama with a blue backdrop. Both older files stay published (#4566).
