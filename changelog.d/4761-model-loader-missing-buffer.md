- **A `.gltf` whose external `.bin` buffer cannot be read no longer loads as a model with no geometry ([#4761](https://github.com/sceneview/sceneview/pull/4761)).** `ModelLoader.load*Async`, `loadModel*` and `rememberModelInstance` now fail such a load: the model is destroyed, the caller gets `null`, and a `Log.w` names the file. The synchronous `createModel` and `createInstancedModel` destroy the model and throw `IllegalArgumentException`; a resolver that throws anything else also destroys the model before the error propagates. In both paths, a texture that cannot be read is logged and skipped, and the model loads without it. `createModel*` no longer passes `data:` URIs to the resource resolver.
