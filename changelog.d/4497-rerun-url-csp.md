- **Website: a recording hosted elsewhere opens on the AR session page ([#4497](https://github.com/sceneview/sceneview/issues/4497)).** `sceneview.github.io/rerun/?url=<link to a .rrd>` is the link the apps and the docs tell you to share, but the page's own security policy only let it download from a fixed list of hosts, so a recording on your own domain, an R2 or S3 bucket or a GitHub repository never loaded. The page now downloads from any `https` address; nothing else in its policy changed. The host still has to allow cross-origin requests (CORS), and the docs now say so and name what works: a public GitHub repository's `raw.githubusercontent.com` link and GitHub Pages do, an R2 or S3 bucket does with a CORS rule, a GitHub release asset does not. When a link cannot be opened, the page says why on screen instead of showing an empty viewer: the host forbids the read, there is no file at the address, the file is not a Rerun recording, or the link does not end in `.rrd`.
