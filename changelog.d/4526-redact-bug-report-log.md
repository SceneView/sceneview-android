- **Bug report: file paths, links and e-mail addresses in the app log are masked before the report leaves the phone ([#4526](https://github.com/sceneview/sceneview/issues/4526)).** The log a report carries could name a file you picked — `cannot load content://…/My flat.spz`, a `FileNotFoundException` on `/storage/emulated/0/Download/…` — and the GitHub issue it pre-fills is public. `content://` and `file://` locations, paths under your storage and the app's per-user data, document ids, e-mail addresses, URL credentials and query strings, and the name of a model you opened with SceneView now read `<redacted>` in the GitHub issue, the share text and the attached file, while tags, timestamps, stack traces and the file extension stay. A new "Preview the attached report" link in the sheet shows exactly what is sent.
